# Retrocoder Portfolio Recreation

Static HTML, CSS, and vanilla JavaScript recreation of the supplied reference site.

## Run locally

Open `index.html` in a modern browser, or serve this folder with any static file server. No install or build step is required.

## Notes

- Navigation, smooth anchor scrolling, the responsive mobile menu, progress bar, hover states, terminal cursor, and reduced-motion handling are included.
- The contact form validates in the browser and explicitly does not send email. Connect it to a backend or form provider before using it for production contact submissions.
- The source CSS preserves the reference site's responsive layout and visual system.
